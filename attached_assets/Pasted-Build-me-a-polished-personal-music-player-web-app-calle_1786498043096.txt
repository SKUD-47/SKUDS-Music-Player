The app should run entirely in the browser for music playback.

        ↓

        ↓

==================================================
TECHNOLOGY
==================================================

Use:

- React
- Vite
- TypeScript if useful
- Modern CSS or Tailwind

Do NOT create a complicated backend.

Use the browser's HTML5 Audio API for playback.

Use IndexedDB to persist imported music/library information locally in the browser.

Do NOT store actual audio files in localStorage.

==================================================
IMPORT MUSIC
==================================================

Create a prominent button:

"+ Import Music"

When clicked, open the browser file picker.

Allow multiple audio files to be selected.

Support common formats:

- MP3
- WAV
- M4A
- AAC
- OGG
- FLAC when supported by the browser

Also support drag-and-drop.

The user should be able to drag music files onto the app and have them imported.

IMPORTANT:

A website cannot automatically access a USB drive.

The user must explicitly select the files using the browser's file picker.

If supported by the browser, also provide:

"Import Folder"

using directory selection.
