# 1. AUTOMATIC SONG ARTWORK — THIS IS THE MOST IMPORTANT PART

### Read the song metadata first

Use whatever metadata is already available for the song, including:

* Song title
* Artist
* Album
* Album artist
* Track number
* Year/release date
* Any embedded artwork metadata
* Any other useful ID such as ISRC, album ID, or MusicBrainz ID if available

### Priority order

Use this order:

**1. Embedded artwork**

If the audio file already contains album artwork, use that first.

Do not search the web if the file already has valid embedded artwork.

**2. Metadata-based lookup**

If there is no embedded artwork, search a music metadata/artwork service using the song metadata.

The search should prioritize:

`Artist + Song Title + Album`

rather than searching only the song title.

For example:

`Daft Punk - Get Lucky - Random Access Memories`

should be much more accurate than simply searching:

`Get Lucky`

Use a reliable music catalog/API as the primary source. Apple's music/iTunes search APIs are one possible source because their search results can identify songs/albums and include artwork URLs.

**3. Web fallback**

If the metadata API cannot find a confident match, then use a web/image search fallback.

The goal is NOT to grab the first random image containing the song title.

The system should try to find the **actual album/single artwork**.

Prefer:

* Official artist artwork
* Official album/single artwork
* Recognized music catalog artwork
* High-resolution square artwork

Avoid:

* Fan art
* YouTube thumbnails unless necessary
* Random wallpapers
* Artist photos that aren't album artwork
* Unrelated images
* Duplicate/incorrect releases
